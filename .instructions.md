# Kutlerri Development Guide

## Project Overview

Kutlerri is a Next.js 16 workspace management application with comprehensive RBAC (Role-Based Access Control) system.

**Tech Stack:**

- Next.js 16.2.9 with Turbopack
- React 19.2.4 with TypeScript 5
- Supabase PostgreSQL + Auth
- ShadCN/UI + Tailwind CSS 4
- Vercel deployment

## RBAC System

### Organization Roles (5 Tiers)

1. **super_admin** (Level 5) - Full system access
2. **admin** (Level 4) - Organization management
3. **manager** (Level 3) - Team management + employee assignment
4. **employee** (Level 2) - Task execution + basic access
5. **viewer** (Level 1) - Read-only access

### Team-Level Roles (4 Types)

- **team_lead** - Leads team, assigns tasks
- **senior_member** - Senior contributor
- **member** - Regular team member
- **guest** - Limited guest access

### Permission System

See [src/lib/permissions.ts](src/lib/permissions.ts) for:

- 49 permissions × 5 org roles matrix
- Role hierarchy logic
- Navigation visibility rules
- Permission checking utilities

## Setup Instructions

### 1. Environment Setup

```bash
# Install dependencies
npm install

# Setup Supabase environment variables
# Add to .env.local:
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
```

### 2. Database

- Migrations in `supabase/migrations/`
- Tables: profiles, organizations, organization_members, teams, team_members
- RLS policies enforcing data access

### 3. First-Time Setup

1. Create account on login page
2. Go to `/init` - it appears automatically when system is uninitialized
3. Enter super_admin email (e.g., roychoudhury.124@gmail.com)
4. System creates organization and assigns super_admin role
5. Log in and start assigning roles to employees

## Key Features

### Employee Management

- **Location:** Employees page (super_admin/manager-only)
- **Tabs:**
  - List: View and change existing employee roles
  - Add: Manually add employees with email/name/role
  - Import: Bulk import from XLS file

### Team Management

- **Location:** Teams page (manager+ only)
- **Features:**
  - Create and manage teams
  - Add employees with team-level roles
  - Update team member roles
  - Remove team members

### Permission-Based UI

- Sidebar navigation filtered by user role
- PermissionGuard component for conditional rendering
- PermissionButton for action validation
- RoleBadge for role display

## Development

### Server Actions Pattern

All protected server actions start with permission check:

```typescript
export async function protectedAction() {
  try {
    const { userId, orgId, role } =
      await verifyPermission("requiredPermission");
    // Safe to proceed
  } catch (error) {
    return { success: false, error: error.message };
  }
}
```

## Troubleshooting

### Navigation Items Hidden

- **Cause:** User has no organization_members record or null role
- **Fix:** Assign role via Employees page or Supabase table editor

### Server Action Permission Errors

- **Cause:** User lacks required permission
- **Fix:** Assign higher org role or specific team role

### Build Failures

```bash
# Clean and rebuild
rm -rf .next
npm run build
```
