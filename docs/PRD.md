# Kutlerri Workspace - Product Requirements Document

Kutlerri Workspace is a Linear.app clone focused on high-performance issue tracking and project management.

## Navigation & Layout
- Sidebar matching Linear patterns.
- Views: Home, My Issues, Inbox, Projects, Cycles, Roadmap, Teams, Search, Favorites, Settings.
- Dark mode and light mode support.

## Issue Architecture
- Issue Identifiers (e.g., `KT-1`)
- Relationships: Parent/Child, Related, Blocked By, Blocks, Duplicates
- Properties: Estimates, Labels, Milestones
- Linear-style issue drawer/detail panel for quick editing.

## Inbox
- Sections: Assigned to me, Mentions, Status updates, Comments, Completed work

## Saved Views & Favorites
- Ability to create and manage saved views.
- Favorites for quick access in the sidebar.

## Interactions
- Command Palette (`Ctrl+K` / `Cmd+K`)
- Keyboard Shortcuts:
  - `C`: Create issue
  - `Q`: Command palette
  - `A`: Assign
  - `E`: Edit
  - `M`: Move

## Planning & Tracking
- Milestones
- Roadmap dependencies
- Cycles
- Activity Feed
- Realtime updates
- Notification center
- Search across all entities
